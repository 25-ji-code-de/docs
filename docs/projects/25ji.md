# 25時作業風景

25時作業風景是沉浸式学习陪伴页：番茄钟、时间同步背景、Project SEKAI 曲库，并通过 **Gateway `/user/sync`** 做云同步。

## 项目信息

| 项 | 值 |
|----|-----|
| 类型 | 学习工具 |
| 技术栈 | 原生 JS, HLS.js, Web Audio |
| 生产 | [25ji.nightcord.de5.net](https://25ji.nightcord.de5.net) |
| GitHub | [25-ji-code-de/25ji-sagyo](https://github.com/25-ji-code-de/25ji-sagyo) |
| 认证 | SEKAI Pass（`js/utils/auth.js`，与 hub 对齐） |

## 功能特性

- 番茄钟 / 世界时钟 / 健康提醒
- 背景视频与现实时间同步
- 曲库搜索（假名/罗马音）与 CD 播放器
- 成就与本地统计
- 登录后：`DataSync` 双向合并到 Gateway（`project=25ji`）
